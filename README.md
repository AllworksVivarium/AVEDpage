# AVED · 万业携生

一个以公司内网为舞台的互动网站。你可以建立员工档案、阅读内部通告、参与论坛讨论，也可以到娱乐空间玩几局，或去 Sloper 酒吧坐一会儿。

## 开始使用

1. 打开活动方提供的网站入口，使用活动方分配的账号登录。
2. 在个人面板设置内网 ID、头像、配色与背景。
3. 通过左侧边栏进入通告、员工目录、收容档案、论坛、娱乐空间和 Sloper。

右上角的主题按钮可循环切换跟随系统、日间和夜间模式。页面适配手机与电脑，音效和特效可在设置中调整。

## 交流与探索

- **内部通告**：阅读公司公告，参与实名留言。
- **匿名论坛**：浏览主题摘要、回帖数和浏览量，进入帖子参与讨论；回复提醒保留近期消息，支持逐条阅读。
- **员工与收容档案**：查看人员资料、部门信息和收容内容。
- **个人面板**：管理头像与内网 ID，查看余额、成就、个人纪录，选购背景。

## 娱乐空间

| 玩法 | 内容 |
| --- | --- |
| 高空速降 | 同乘一班直升机，选择开伞时机，查看安全落地与开伞深度战绩 |
| 随便跑跑 | 为五位小动物选手竞猜头名或末名，在看台无线电交流 |
| 智斗太姥 | 三人或四人牌桌、电脑补位，分别记录地主与农民胜场 |
| 异常回路 | 五轮五线转轮、组合奖励、隐藏收容协议 |
| 刮刮乐 | 选择票种、刮开奖面，收集隐藏成就 |
| 股市 | 买涨买跌、管理仓位、查看行情与交易记录 |

游戏使用站内 A 币。各玩法的投入、返还与操作方式可在页面内查看。战绩榜采用像素表头，榜首带专属标记；成就与收容协议在解锁后展示详情。

## Sloper 酒吧

在像素吧台点一杯饮料，和邻座碰杯、聊天，或者翻开杯垫看看留言。

- 酒单包含免费饮用水和多款饮品。
- 点击「喝一口」饮用，饮品按种类分次喝完。
- 可选择实名或匿名聊天，邀请其他客人碰杯。
- 支持请客和一小时全场买单。
- 调酒师按设备本地时间问候，个人对话显示在自己的页面。
- 醉意随时间消退，长时间离开后桌上的旧饮品会被清理。
