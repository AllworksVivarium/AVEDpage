# Additional typography resources

IBM Plex, SIL Open Font License 1.1; license included in `OFL-IBM-Plex.txt`.
Official project: https://github.com/IBM/plex

Downloaded 2026-11-09 from the official repository:

- `IBMPlexSans-Regular.woff2`: `packages/plex-sans/fonts/complete/woff2/IBMPlexSans-Regular.woff2`
- `IBMPlexSans-SemiBold.woff2`: `packages/plex-sans/fonts/complete/woff2/IBMPlexSans-SemiBold.woff2`
- `IBMPlexSansHebrew-SemiBold.woff2`: `packages/plex-sans-hebrew/fonts/complete/woff2/IBMPlexSansHebrew-SemiBold.woff2`
- `IBMPlexSansSC-SemiBold.woff2`: `packages/plex-sans-sc/fonts/complete/woff2/hinted/IBMPlexSansSC-SemiBold.woff2`

Regular SC, regular Hebrew, Mono and the archived Jinghua common-character font reuse existing project resources. The SC semibold is an approximately 4 MB complete font; it is not preloaded on the login screen. Resource subsetting and further weight reduction remain a separate performance pass after art approval.
