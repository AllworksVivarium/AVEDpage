# 刮刮乐票面区分

- 幸运号签沿用原规则。
- 三印报喜随机使用七种印章中的不同图案成组；有奖票可出现 1 至 4 组，各组金额合计严格等于服务端奖金。中奖组不会和非中奖格组成额外的误中奖。
- 步步添彩从 0 层出发，五个刮开格表示升降或停留，每次升降最多两层，路线始终在 0 至 5 层内。
- 普通终点 1 至 5 层分别对应 0.5、1.2、5、20、100 倍；0 层无奖金。概率为 1/12,500,000 的 2000 倍超级大奖在第 5 层显示。
- 一键刮开直接显示全部升降、终点和金额；手动跳着刮时，尚未连通的路线不提前显示后续层数。下一张免费草稿会清空终点。
- 五层奖池将原奖级分配至相邻奖级，并修正整数权重舍入，保持总概率、配置返还率和炸弹概率。炸弹扣费及核准印逻辑沿用原规则。
- 客户端只展示票面。奖金、扣费、税费和不可变票据仍由现有事务一次结算。
