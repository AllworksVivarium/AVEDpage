# 收容物账号与卷宗

`server-containment-dossiers.mjs` 为玩家及系统收容物账号关联一份持久卷宗，通过唯一的 `dossiers.employee_id` 连接账号。后台收容卷宗、公开卷宗接口和玩家收容一览读取同一张表。

安装时，姓名唯一且恰好有一份同名未关联旧卷宗的账号会沿用旧卷宗，保留编号、正文和评议；不明确的重名不会自动认领。没有卷宗的收容物账号自动建立基础记录。创建收容物账号或把普通账号转为收容物时也会自动补齐。

后台可以修改卷宗正文、收容措施、补充资料、状态、编号和图片。名称与收容分类在账号及关联卷宗间同步；玩家自己修改个人简介不会覆盖完整卷宗。账号被删除后，卷宗保留并解除关联。关联中的卷宗在账号名册中管理身份，不单独删除。

收容物玩家的默认四份展示中，第一份固定为自己的关联卷宗，后三份随机且不重复。按姓名检索及分类筛选仍尊重筛选条件；普通员工继续随机四份。每次重新进入收容一览都会读取最新卷宗，避免后台修改被本次登录缓存遮住。

验证包括旧卷宗关联与重名保护、后台编辑与权限、个人简介独立、名称及分类同步、重启后记录稳定、本人优先抽样。

## 卷宗编辑与阅读

- 管理端由 `public/admin-dossiers.js` 提供检索、分类与状态筛选、每页 12 份卷宗、宽屏编辑及同源玩家端预览；窄屏在编辑和预览之间切换。草稿只保存在当前浏览器，并按管理员账号和卷宗 ID 隔离，不会自动发布。
- `dossiers.abstract` 为选填短摘要，旧档案无需补录；档案板优先使用摘要，完整正文仍保留在 `summary` 中。
- `public/dossier-content.js` 为后台预览、档案板正文及独立阅读页共用的安全渲染器。支持小标题、加粗、列表、引用和表格，访谈按发言人排版；保留现有遮盖、乱码标记及效果关闭行为。
- 卷宗独立地址为 `/player#/containment/{数据库ID}`，页码为 `?page=2`。地址不受编号、名称修改影响，仍要求内网账号登录；刷新、登录后会恢复到目标卷宗。长文按段落分页，支持目录、前后翻页及连续阅读；动效遵守特效开关和减少动态效果设置。
- 默认只使用现有总配图，不展示空附图区域。资料模块预留选填 `attachment: {imageUrl, caption}` 数据接口，仅允许站内素材或卷宗图片地址；本轮不提供模块附图上传器。
