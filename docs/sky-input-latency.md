# 速降开伞响应

点击开伞后，浏览器立即播放开伞音效并展开自己的降落伞，无需等待 HTTP 回包。该画面只是一份临时显示状态，原始服务器快照、乘员名单、钱包、奖金和安全判定均不变。确认前倍率显示“开伞确认中”，不会提前庆祝或修改余额。

服务端回复或 SSE 确认后使用真实状态；若判定坠落，临时降落伞随即由坠落状态替换。换架次、换账号都会清理临时显示。连续点击复用同一个请求。请求超时或丢失时只读取一次当前架次核对结果，不自动重复 POST。

开伞请求仍仅发送 `{round}`。客户端的时间、深度、奖金或余额不参与结算。服务端在收齐请求体后记录接收时间，避免后续内部查询处理再增加判定延迟，也不能通过拖延发送请求体来补填过去的开伞时间。网络补偿使用服务器签发的单次令牌测量往返时间，取最近两分钟内最多五次测量的最小值的一半，最多回溯 250 毫秒。没有有效测量时不回溯，客户端不能提供点击时间或自报延迟。第一次测量仍可能被人为拖延，但补偿始终受 250 毫秒上限约束。

按钮在主指针按下时发送，不等待松开；随后产生的 click 不重复发送，键盘和辅助操作继续可用。

安全线公开和未开伞乘员的统一结算延后 300 毫秒，容纳正常传输中的开伞请求；成功与奖金仍按补偿后的服务器时间、原始安全线和深度计算。公开后不能补开、补发或追改旧结算。网络抖动、上下行不对称及超过上限的延迟仍可能使临界开伞失败，不能保证 1 米开伞成功。每班通常新增一次小型校时 POST，不新增高频轮询。

服务端先向操作人发送结算回复，再在下一轮事件循环向机舱广播。同一轮内的多次操作合并为一轮广播，减少同时操作时重复查询和序列化；保留既有 SSE 和定时恢复机制，无新轮询或第三方依赖。

实现：`public/sky-ui.js`、`public/player.js`、`server-sky.mjs`、`server-input-timing.mjs`。验证：

```sh
node --test tests/sky-input.test.mjs tests/sky-input-server.test.mjs tests/sky-multiplayer.test.mjs tests/gameplay-achievements.test.mjs
```

包括延迟 600 毫秒的回包、立即展开、真实失败覆盖、丢失回包核对、重复点击、金额隔离、先回复后广播及慢请求体不能回溯判定。1 米和 10 米开伞成就继续按服务端实际结算数据计算，安全线仍在统一揭晓时公开。


## 共享时钟、智斗太姥与竞速

`public/game-clock.js` 用既有 HTTP 请求及服务器令牌的往返测量估计服务器时间，SSE 到达不会再次把钟拨慢。拒绝排队尖峰，测量窗口最多两分钟；页面失去同步时仍限制动画外推，不预测输赢或钱包。换账号会关闭旧联机流，旧请求的回包不能覆盖新账号余额。

智斗太姥每张桌、每位真人约每分钟校时一次。联机真人仍有 30 秒，超时托管在其最近有效最小 RTT 的一半之后执行，额外等待最多 250 毫秒；没有有效测量则无额外宽限。服务器收齐请求体后计时，迟于宽限线的指令不能用客户端时间回溯，已执行的托管不撤销。电脑房的真人仍不限时。

回合使用服务器 `turnId` 标识。同一回合内，其他座位切换托管等只改变桌面修订的操作，不应误拒已发出的合法叫分、出牌或不出；旧回合的指令仍拒绝。托管切换不会延长本轮原有的 30 秒。扣款与结算依然幂等。提交后先确认，再合并同一事件循环的广播，公开头像只在这一批广播内复用，私人手牌仍按接收者单独生成。相同的 HTTP 回包与 SSE 状态不重复重建整个牌桌。

竞速保持严格封盘，开赛后不接受补下注。客户端补偿用于时钟和动画同步；服务器在开赛、结束、下一场边界使用一个共享唤醒器，避免等待下一秒心跳才切换。规则解析缓存、历史版本检索索引及同批下注广播合并减少重复计算。

无线电仍有即时发送推送，保留 20 秒连接与授权检查。心跳按聊天室共享查询和序列化，不再给每位听众重复读取同一批 80 条聊天记录。校时 POST 不清空只读名录缓存；财务写入和登出仍使缓存失效。

验证覆盖 `tests/card-input-latency.test.mjs`、`tests/game-clock.test.mjs`、`tests/derby-phase-timing.test.mjs` 及原有联机、资金与隐私测试。
