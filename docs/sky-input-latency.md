# 速降开伞响应

画面使用临时显示状态；服务器快照负责乘员名单、钱包、奖金和安全判定。

服务端回复或 SSE 确认后使用真实状态；若判定坠落，临时降落伞随即由坠落状态替换。换架次、换账号都会清理临时显示。连续点击复用同一个请求。

开伞请求仍仅发送 `{round}`。网络补偿使用服务器签发的单次令牌测量往返时间，取最近两分钟内最多五次测量的最小值的一半，最多回溯 250 毫秒。第一次测量仍可能被人为拖延，但补偿始终受 250 毫秒上限约束。


安全线公开和未开伞乘员的统一结算延后 300 毫秒，容纳正常传输中的开伞请求；成功与奖金仍按补偿后的服务器时间、原始安全线和深度计算。

服务端先向操作人发送结算回复，再在下一轮事件循环向机舱广播。同一轮内的多次操作合并为一轮广播，减少同时操作时重复查询和序列化；保留既有 SSE 和定时恢复机制，无新轮询或第三方依赖。

实现：`public/sky-ui.js`、`public/player.js`、`server-sky.mjs`、`server-input-timing.mjs`。验证：

```sh
node --test tests/sky-input.test.mjs tests/sky-input-server.test.mjs tests/sky-multiplayer.test.mjs tests/gameplay-achievements.test.mjs
```

1 米和 10 米开伞成就继续按服务端实际结算数据计算，安全线仍在统一揭晓时公开。

## 共享时钟、智斗太姥与竞速


智斗太姥每张桌、每位真人约每分钟校时一次。联机真人仍有 30 秒，超时托管在其最近有效最小 RTT 的一半之后执行，额外等待最多 250 毫秒；没有有效测量则无额外宽限。电脑房的真人仍不限时。

回合使用服务器 `turnId` 标识。同一回合内，其他座位切换托管等只改变桌面修订的操作，不应误拒已发出的合法叫分、出牌或不出；旧回合的指令仍拒绝。扣款与结算依然幂等。提交后先确认，再合并同一事件循环的广播，公开头像只在这一批广播内复用，私人手牌仍按接收者单独生成。

客户端补偿用于时钟和动画同步；服务器在开赛、结束、下一场边界使用一个共享唤醒器，避免等待下一秒心跳才切换。规则解析缓存、历史版本检索索引及同批下注广播合并减少重复计算。

无线电仍有即时发送推送，保留 20 秒连接与授权检查。校时 POST 不清空只读名录缓存；财务写入和登出仍使缓存失效。

验证覆盖 `tests/card-input-latency.test.mjs`、`tests/game-clock.test.mjs`、`tests/derby-phase-timing.test.mjs` 及原有联机、资金与隐私测试。
