# 员工牌桌本地预览

入口：员工愉乐室 → 玩法 → 斗地主。三人经典和四人双牌均支持单人、创建房间、房间码加入和电脑补位。本阶段是练习桌，积分只显示牌局底分和倍率，不结算账户余额。

规则：三人一副牌，17 张手牌和 3 张底牌；四人两副牌，25 张手牌和 8 张底牌。四人炸弹为 4—8 张同点数，张数优先；王炸必须四张王。顺子至少 5 张，连对至少 3 对，飞机至少 2 组，不含 2 和王。飞机单翼可带对子，不能复用机身点数；对子翼要求不同点数。叫分无人响应则重新发牌。自动托管时限为 30 秒。

服务器负责私有手牌、合法出牌、轮次、叫分、托管和胜负。房间状态写入 SQLite；动作带版本号与请求 ID。SSE 只在状态变化时推送每个玩家自己的视图，15 秒心跳；浏览器倒计时和动画不发送请求。切出牌桌页面关闭推送，回桌恢复状态。

头像：新上传图片生成 256×256 WebP。牌桌和速降请求 64×64 的独立缩略图，已有本地头像首次请求时生成并持久缓存，相同版本并发请求合并。最多同时运行两个解码任务，限制输入像素数，缓存有鉴权、ETag 和版本参数。旧的外链头像不由牌桌下载原图，暂用文字头像。没有改写用户原有的外链地址。

安装：`npm ci`。新增依赖仅 Sharp，锁文件含跨平台预编译包；Docker 构建自动安装。上线后继续作为练习桌运行，账户结算另行确定。

规则识别的分组方法和牌型分支改编自 [NFraw/Tongzhuo](https://github.com/NFraw/Tongzhuo/blob/main/games/landlord/hand.ts)，原始 blob 为 `609b430d0e03e253be36d646d7bb0d8ad7f524e0`。许可证为 MIT，见 `docs/third-party/tongzhuo-LICENSE.txt` 与玩家资源 `/licenses/tongzhuo.txt`。原始文件保留于 `tools/vendor/tongzhuo-hand.ts`。本地适配修复了比较张数、王炸优先级、飞机带牌，并增加四人规则、合法选牌、电脑决策。未引入上游框架、音频或美术。

美术为 AVED 自绘 CSS/SVG 卡牌与桌面，参考复古像素卡牌的质感，没有使用 Balatro 游戏素材。

核验：牌型与牌局规则、四会话同桌、私有手牌、重复／过期动作、重连恢复、缩略图缓存，以及头像上传、登录、速降相关回归。手机浏览器实际验证了叫地主、33 张手牌、选牌状态与牌型提示。
