# 账号永久清理

管理端删除员工接口调用 `server-account-erasure.mjs`。删除操作同时清理当前数据库和 `daily-backups` 中现有的每日、五日快照，不创建额外数据库备份。

按账号主键、外键和已知软关联清理：账号、凭证、个人资料、曾用名、头像缩略图、公告及评论、论坛发言、生活记录、游戏和酒吧聊天、图片审核归档、发言修订、活动日志、账号历史、收容卷宗、游戏/交易/竞拍/点歌/礼物记录及相关通知。删除机器人账号也删除其代发身份和代发内容；删除操作员不删除独立机器人账号。

删除前取消相关未结束牌局，向其他参与者退回锁定款；未领用留酒的收件人被删时向存酒人退款。其他账号的余额保持原值加应退资金。公司基金保留金额并移除账号和流水归属；其他账号的捐赠流水保留金额，移除被删者署名。用户真名可能相同，因此不以真名或正文全文匹配删除其他人的独立内容。

清理先计算关联行闭包，在保留外键检查的事务内执行，失败时回滚。每份快照通过账号 ID、创建时间及用户名/密码散列核对身份，防止误删被复用的 ID。所有数据库完成清理与校验后再提交，快照先于当前数据库提交。跨文件提交不等同于单数据库原子提交；异常中断时必须检查全部文件后重试。

账号删除和定时备份共用数据目录内 `maintenance-lock.sqlite` 的 SQLite 写锁，防止旧快照并发覆盖清理结果。此文件只用于互斥，不保存账号信息。删除使用 `secure_delete` 并在提交后截断 WAL；SQLite 文件系统以外的导出、磁盘历史快照和已经下载的副本不在应用可撤回范围内。

提交后清理在线状态、牌桌与排行缓存，关闭该账号的游戏和聊天订阅，广播最新状态。删除期间完成的头像生成任务会再次核对源账号，不能回写已经删除的头像缓存。

验证：`tests/account-erasure.test.mjs`、`tests/account-erasure-http.test.mjs`，以及管理内容、论坛、牌桌、酒吧、账号和维护任务回归测试。
