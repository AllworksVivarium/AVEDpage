# 联机速降核心交接

本提交只承载联机速降核心和用户明确提出的游戏内交互。基于 main b1319e8；没有移入其他窗口的整页前端设计，也不包含试玩数据库、凭据或预览账号。

## 新窗口如何接入

- 独立模块：public/sky-ui.js、public/sky-scene.js、public/sky-pixel.css。
- 保留新窗口自己的 public/player-terminal.html，仅补入 sky-pixel.css，并按 sky-scene.js -> sky-ui.js -> player.js 顺序加载；同步更新缓存参数。
- public/player.js 只改三处：playSfx 增加 sky-* 音效；AVEDSkyUI 构造参数传入 playSfx；登机成功改用 skyUI.feedback('您已登机')。
- 其余整页样式、侧栏、排版、字体设置保留新窗口版本。不要用本分支的 player.js / player-terminal.html 整文件覆盖新窗口文件。
- 新版字体系统如覆盖游戏字体，保留 sky-pixel.css 内 scoped aved-type-system 层规则与 panel.dataset.typeIgnore；头像姓名保持高清小字。
- 可以 cherry-pick 本分支的单次核心提交；冲突时仅移入上述游戏接入片段，保留新版页面布局。

## 后端

- server-sky.mjs：真实共享架次与 SSE；服务器决定扣款、开伞、坠落与结算；隐藏安全线直到揭晓。历史接口同步隐藏未揭晓安全线。
- server-company-robots.mjs 暴露现有机器人 list 服务；server.mjs 将其注入 installSky。
- 一名真人登机时，在起飞点补一名余额至少100的后台机器人；无人班不自动花机器人余额，两名及以上真人不补机器人。
- 机器人每次投入不超过1000且不超过余额；登机事务中随机一次180..600米开伞深度及 jump_at，落库后不重抽。计划不发给客户端，不参照隐藏安全线。
- 正常返还与真人走同一账本、结算和幂等路径；重启后保留计划及结果。一个共享揭线定时器，无每个机器人独立定时器。
- 每次广播共用乘员查询；没有观看者和待结算乘员时停止数据库轮询。
- 旧个人飞行/旧版未结算架次有既有退款迁移；上线前应备份数据库。已开始班次保留自己的 rules_json，新参数从新班次生效。

## 固定数值与回报口径

- 登机12秒，下降25米/秒，落地结算展示14秒。
- 安全线分布150..900米，均值399.94米；150..179米概率0.5%。当前没有2000米安全线事件。
- 新班次成功返还=floor(投入*开伞深度/207)，含本金；越线未开伞归零。
- 130%基准：固定约300米开伞时，计入所有坠落，理论平均返还约129.71%；最优固定299米约130%。这不是任何策略或所有玩家都保证130%。180..600米均匀随机机器人策略的理论平均约76.36%。

## 用户明确要求的画面与交互

- 机舱仅显示前8人，乘员表保留全部；独立开伞、共享安全线。
- 城市在平均安全线约400米附近完整展露，之后封顶，极大深度不继续上升；地面独立约420毫秒升起。
- 未开伞头像约650毫秒猛坠碎裂，之后已开伞者缓降；开伞高度影响少量飘落时差。
- 天空、城市、地面和乘员分层，静态天空/城市缓存；画面上限30帧，页面隐藏停止绘制。
- 中央悬浮像素按钮共用登机/开伞，也显示旁观；像素字约14px，“返还”13px，辅助说明11px，结算12px。
- 登机/开伞确认在游戏中间的半透明框显示，背景不透明度30%。
- 投入自由输入，右侧 ×2；评论自动进入实时弹幕；保留弹幕开关。
- 无本班封签、专门发弹幕入口、场景底部公司小字；保留外层中英文品牌。
