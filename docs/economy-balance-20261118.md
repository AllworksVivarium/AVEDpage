# 收入与装饰定价

- 每日签到：8,000，每自然日一次。
- 整点补给：2,000，每小时一次，全天 24 小时可领，无额外每日次数上限；未领取的时段不累积。
- 一键发薪：每人 200,000，员工和部长可领；发放频率仍由管理端决定。
- 收容物黑入：每日一次，60,000 / 65,000 / 75,000 等概率，三日期望共 200,000。
- 纹理：每种 20,000；付费配色：每套 50,000；信号球体背景：100,000。
- 点歌：每首 30,000。
- 可购买饮品：原价上调约 20%，四舍五入到十位；矿泉水免费。未开放购买的空杯不调价。
- 污染模式：员工 500,000，收容物 100,000；应急低保维持原值。

已购外观不补差价；历史签到、补给、账本和已寄存酒款保持原值。同一小时内已领取的旧补给不能重复领取。

三天内每天签到并领取三次补给，共 42,000；加一次发薪或三天黑入期望，共 242,000。若每天领取全部 24 个时段，三天签到与补给合计 168,000；加一次发薪或三天黑入期望，共 368,000。
