# 小游戏成就

玩家端继续只显示已解锁成就，沿用个人主页的成就档案。默认新增 17 项；管理端可调整名称、描述、门槛和启停状态，升级不会覆盖管理员修订。

| 玩法 | 成就 | 条件 |
| --- | --- | --- |
| 速降 | 平安落地 | 首次安全开伞 |
| 速降 | 极限开伞 | 开伞深度距离本场安全线不超过 10 米，且安全开伞 |
| 速降 | 奇迹开伞 | 开伞深度距离本场安全线不超过 1 米，且安全开伞 |
| 速降 | 穿云而过 | 深度至少 800 米，且安全开伞 |
| 刮刮乐 | 开门见彩 | 单张返还超过该张投入与追加扣款之和 |
| 刮刮乐 | 纸上惊喜 | 单张返还至少为投入的 10 倍 |
| 刮刮乐 | 纸上奇迹 | 刮出后台票种规则中的隐藏大奖 |
| 异常回路 | 五连贯通 | 一条有效线路从左至右五连 |
| 异常回路 | 双重共振 | 一局触发至少两种组合机制 |
| 异常回路 | 全频共振 | 一局触发三种组合机制 |
| 下班竞速 | 先下班一步 | 押中第一名 |
| 下班竞速 | 压轴登场 | 押中最后一名 |
| 下班竞速 | 首尾通吃 | 同一玩家、同一场第一与最后名均押中 |
| 斗太姥 | 初试牌锋 | 亲自出过牌并获胜 |
| 斗太姥 | 当家做主 | 亲自出过牌并以太姥身份获胜 |
| 斗太姥 | 少姥合伙人 | 亲自出过牌并以少姥身份获胜 |
| 斗太姥 | 翻倍时刻 | 亲自出过牌并在至少 8 倍的牌局获胜 |

距离按服务器确认的开伞深度计算，包含恰好 0、1、10 米的情况。奇迹开伞同时满足极限开伞。速降成就统一延迟到安全线公开后签发；开伞后立刻查个人主页不能提前探知安全线。

成就不发放额外货币，不修改任何赔率和游戏结算。管理端门槛仍使用“大于等于”：次数类可调整为累计多次，深度与倍率类可调整为更高历史记录。

实现位于 `server-game-achievements.mjs`。结算写入 `game_tickets` 后，SQLite 触发器在同一事务内更新 `gameplay_achievement_metrics` 并签发成就；事务回滚时一并撤回。速降在 `sky_flights.ended_at` 从 0 变为已公开时计算本场参与者。竞速双中按票据先后顺序只计算一次，不跨玩家或架次。

首次启动按已保存且可验证的历史票据补发一次，后续增量更新，无新增轮询请求。仍在进行中的速降留待安全线公开。维护退回、迁移退回、演示票不计；没有保存手动出牌证据的旧牌局不能推定达成手动成就。既有帖子、游戏票据和账本不变。

验证：`node --test tests/gameplay-achievements.test.mjs tests/personal-multiplayer.test.mjs tests/sky-multiplayer.test.mjs`，覆盖贴线边界、隐藏安全线、失败与退回、竞速不同结算顺序、手动出牌、事务回滚、历史补发及重复启动。
