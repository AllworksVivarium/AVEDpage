# 窗口与反馈规范

本轮只调整弹出界面，不改论坛分页、游戏规则或后端接口。工作分支：`codex/window-consistency-20261109`，基于已发布的 `b39db82`。

## 类型与现有入口

| 类型 | 现有入口 | 规则 |
| --- | --- | --- |
| 编辑窗口 | 个人档案、配色、背景、发言修订、管理端编辑 | 居中、窄标题栏、内容内滚动 |
| 内容窗口 | 牌桌规则、论坛提醒、演绎编排、表情选择 | 同一边框与间距，按内容选择尺寸 |
| 操作确认 | 清零、删除、审核、捐赠、选票 | 明确确认/取消，危险操作默认聚焦取消 |
| 浮层 | 娱乐室玩法选择 | 保留触发点附近的位置，透明遮罩，不挡整页 |
| 抽屉/展开区 | 左边栏、账户流水、游戏记录、成就、最高奖金 | 保留原锚点与加载逻辑，短促展开 |
| Toast | 右上角操作反馈 | 不抢焦点；同一内容去重，最多三条；可手动关闭 |
| Tooltip | 股市图表数据、原生 title 提示 | 小字、无标题栏，图表提示使用主题色；原生 title 由浏览器显示 |
| Alert | 管理端错误、操作异常、表单内校验 | 需要确认的消息用小窗；字段错误留在对应表单附近 |
| 游戏强反馈 | 刮刮乐大奖、老虎机结果、破纪录 | 保留各自美术及庆祝，不套普通提示动效 |

## 统一尺寸

`public/popup-density.css` 是窗口尺寸和动效的唯一入口，作为第一个级联层优先于旧模块覆盖。

- 小窗 360px，普通窗 440px，内容窗 580px，管理长表单 680px；均限制在屏幕内。
- 手机通常左右各 20px，359px 以下各 16px；使用可用宽度计算，避免桌面滚动条吃掉边距。
- 标题栏 30px、标题 12px、叉号按钮 22px，额外扩展点击区域。
- 内边距 16px，窄屏 14px；说明 12–13px，输入控件 16px，使用现有可读字体。
- 最大高度扣除上下 48px 及安全区，长内容滚动时标题保持可见。
- 配色继续来自玩家三套配色及管理端主题，直角细边框、实色面板、3px 硬阴影。
- 确认/提醒窗口的主按钮使用当前主题重点色，取消按钮使用中性色；两者均有清晰的 1px 边框、轻微凸起和按下反馈，最小尺寸 76×34px。

## 动效

- 普通窗口：120ms、3 步、4px 垂直位移与显现；关闭立即生效。
- Toast：120ms、4px 横向位移；弱提示约 5 秒，警告约 8 秒；悬停和键盘聚焦暂停消失。
- 严重错误：`toast(message, 'error')`，保留至关闭；用边框与屏幕阅读器 alert 区分，不自动抖动或播放音效。
- 侧栏：160ms、4 步宽度变化；记录展开区仅短暂显现。
- 按钮：按下 1px，不使用弹簧、大幅缩放或玻璃模糊。
- 尊重现有“特效关闭”和 `prefers-reduced-motion`。没有新增循环动画、网络请求或动效依赖。

## 调用与交互

`popup-ui.js` 先于业务脚本加载，提供：

```js
AVEDFeedback.toast('已保存', 'success');
AVEDFeedback.toast('请求失败，请重试', 'error');
await AVEDFeedback.alert('无法保存，请检查输入。');
if (await AVEDFeedback.confirm('确认执行这项操作？', {title:'请确认'})) {
  // 原有业务操作
}
```

确认和 Alert 使用原生 dialog，队列串行展示，Escape/关闭均返回取消，恢复触发按钮焦点。不要覆盖 `window.confirm` 或将 Promise 当布尔值。异步事件处理应在 await 前保存 `event.currentTarget`。管理端原有二次确认流程保留。

登录和选票保留原表单处理方式，通过局部观察器补齐 Escape、Tab 范围和背景 inert；普通提示在原生模态窗口打开时放入该窗口顶层，避免被遮挡。自定义确认窗口不点击遮罩直接接受或丢弃编辑。

后续新增窗口应复用这一规范，不再在各模块反复添加尺寸、字体和动效覆盖。原生 title 的自绘替换、全站页面切换动效不在本轮范围。
