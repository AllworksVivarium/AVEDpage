# 论坛付费反应

主题正文和具体回帖可点击打开反应面板，也可使用底部「＋」。选择反应后显示费用，确认才扣款；发言下只展示像素图标与人数。每个账号可对同一发言留下每种反应各一次，重试不重复扣款。没有公开反应人的姓名、内网 ID、头像或账号编号。

图标为原生 16×16 像素 SVG，无性别角色形象。动态使用 CSS steps，关闭特效或减少动态效果设置下静止。遵循现有日夜配色；手机为三列。

`GET /api/player/forum/reactions` 返回服务端价格；`POST` 接收 `{kind:'thread'|'reply',targetId,reaction,confirmed:true}`。扣款与反应写入同一事务，服务端验证余额、公开审核状态与唯一性，不接受客户端价格。反应不向发帖人转账。

详情页按一页回复批量汇总反应，沿用既有论坛轮询和版本机制；无额外计时器、逐条请求或身份查询。隐藏或删除发言禁止新增反应。
