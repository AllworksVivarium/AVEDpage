# 酒吧点歌、留酒与自动常饮

- 点歌：每首 30,000 A 币，留言最多 120 字，可用内网 ID 或真名署名。仅管理端已上架且启用的歌曲可点，空曲库不收费。每人最多同时两首，全场最多二十首。曲目时长由管理端按实际音频填写，30–900 秒；默认 180 秒。排队、曲名、留言和播放时段持久化；静音与音量由各浏览器自行决定，加入时从当前进度收听。管理员下架仍在队列中的曲目时退回点播款。
- 留酒：可指定内网 ID、指定真名，或留给下一位客人。自选饮品，便签最多 120 字，留酒时付清、保管七天。对方可离线；领酒免费，桌上有未喝完的酒时需先喝完。婉拒或到期退回，公共留酒只供一个非发件人领用。每位发件人最多五杯待领；每个身份信箱最多十杯，公共柜台最多二十杯。
- 身份：新收件目录按模式返回独立的随机信箱凭据，仅显示所选称呼，不返回账号编号、用户名或另一种名字。留酒回执无收发双方账号编号；发送人仅见寄存凭单，不获知领用状态、时间或领用者的其他身份。领取不发公共消息。原在线请客回执也改用 incoming/outgoing 标记取代双方账号编号。此改动不声称重构全站已有名录、聊天与在线席位的身份协议。
- 常饮：至少两个营业日、自费点过同款付费饮品三次后，自动识别累计点得最多的一款；并列取最近点的一款。免费水、他人请客、全场买单不计入。酒单标注“常饮”，调酒师用固定台词回应，无需手动登记。调酒师图片仍为静态。
- 新接口：GET `/api/player/bar/contacts?mode=anonymous|real&q=...`；POST `/api/player/bar/jukebox`；POST `/api/player/bar/kept-drinks`；POST `/api/player/bar/kept-drinks/:id`。所有扣款由服务端定价并在 SQLite 事务中完成，点播和留酒均以请求凭据防重复扣款。
- 本地曲库未添加示例歌曲；浏览器完整流程检查使用独立临时数据库及本地静音测试音频。
