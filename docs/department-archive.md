# 部门档案本地接入 · 2026-11-18

采用选定的档案版，入口分为部门展示和员工档案。每次进入名录默认显示部门总览，依次为收容部、武装部、医疗部、科研部、后勤部；点击后显示详情，可返回总览。部门正文使用公司业务口吻；服装图片保留原貌，支持放大。部门介绍下方完整展示对应的人设卡原图，等比适配页面宽度，可点击放大；武装、医疗、科研使用部门图，收容、后勤使用公司通用图。

“公司直属”不作为部门展示。员工档案默认直接列出全部档案：公司直属、未归属五个部门的员工先显示，收容物不参与置前；其余档案跨部门按姓名拼音排列。两部分各自按姓名拼音排序，不再插入部门或职位分组标题。从部门详情进入时，直接筛选本部人员，不修改数据库中的部门归属。

部门切换栏固定为五等分单行，手机与桌面均不换行。移除“全部人员 / 其他职位”一排及重复的员工档案标题；员工档案中再次点击已选部门即可取消筛选，也可重新点击员工档案页签返回全部。下方仅保留紧凑的姓名排序下拉框。

排序可选默认顺序、姓名拼音正序、姓名拼音倒序和姓名笔画顺序。手动姓名排序时，公司直属员工也一起参与，不固定在最前；部门筛选继续对全部档案生效。使用浏览器原生中文 Intl.Collator，数字采用自然顺序，原始姓名用于比较，页面仍转义显示。排序使用已有名录数据；切换排序保留下拉框焦点。

总览及服装选择小图通过固定画框、居中取景和逐图位移统一人物位置；放大查看使用完整原图。员工证件照统一画框和头像取景。

两张黑色西服（suit.jpeg、coat.jpeg）均属公司通用服装。医疗、武装、科研仅展示各自部门服装，不再附加通用西服、风衣区域；收容部服装位置仅保留占位；后勤部默认展示公司西服。黄色防护服未确定归属，未接入。

部门详情不再重复显示统一穿衣说明，改为各部门的“常规事务”。返回区仅显示“← 返回”，采用论坛工具栏的边框、底色与尺寸；“调阅本部员工档案”也使用有边框和底色的按钮。

员工档案沿用现有名录、头像及六维布局，新增个人留言，直接读取 directory 接口已有的 bio 字段。没有人物卡时也正常显示；没有留言时隐藏该段。所有留言经现有 esc 函数转义。

实现位于 public/department-archive.js、public/department-archive.css；player.js 提供现有名录数据并渲染个人留言；player-terminal.html 加载模块。原部门组件保留作模块缺失时的回退。

服装缩略图切换仅更新主图、图版编号及选中状态，不再重建整个部门档案。标题、通用服装区域和缩略图节点保持稳定，避免文字重新排版闪烁，并保留键盘焦点。

验证：directory-roster 与 player-startup 共 13 项通过，包括总览初始状态、部门筛选及取消、直属员工置前、收容物不置前、全员姓名排序和数字自然排序。浏览器核对 714px 与 390px 布局、无横向溢出以及切换排序后的键盘焦点。仅本地修改，未发布。
