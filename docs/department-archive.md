# 部门档案本地接入 · 2026-11-18

采用选定的档案版，入口分为部门展示和员工档案。每次进入名录默认显示部门总览，依次为收容部、武装部、医疗部、科研部、后勤部；点击后显示详情，可返回总览。部门正文使用公司业务口吻；服装图片保留原貌，支持放大。空白人物模板不出现在部门展示中。

“公司直属”不作为部门展示，仅在员工档案中显示为“其他职位”。员工档案默认显示全部人员，按五个部门及其他职位分组；从部门详情进入时，直接筛选本部人员。不修改数据库中的部门归属。

部门切换栏固定为五等分单行，手机与桌面均不换行；“全部人员”和“其他职位”在下方等宽、等高排列，共用部门栏的左右边界、边框及间距，不占用五个部门的位置。浏览器在 390px 与 714px 宽度验证对齐及无文字溢出。

总览及服装选择小图通过固定画框、居中取景和逐图位移统一人物位置；放大查看使用完整原图。员工证件照统一画框和头像取景。

两张黑色西服（suit.jpeg、coat.jpeg）均属公司通用服装。对外页面只写“服装规程”“公司配发”，通过一条内部规程说明穿着场景。医疗、武装、科研服装对应各自部门；收容、后勤暂无专属图，展示西服。黄色防护服未确定归属，未接入。

员工档案沿用现有名录、头像及六维布局，新增个人留言，直接读取 directory 接口已有的 bio 字段，不新增接口或轮询。没有人物卡时也正常显示；没有留言时隐藏该段。所有留言经现有 esc 函数转义。未新增人物卡上传字段或布局自选项。

实现位于 public/department-archive.js、public/department-archive.css；player.js 提供现有名录数据并渲染个人留言；player-terminal.html 加载模块。原部门组件保留作模块缺失时的回退。

验证：directory-roster 与 player-startup 共 12 项通过，包括总览初始状态、部门顺序、详情与员工筛选、其他职位入口及全部人员分组。浏览器验证本地页面。仅本地修改，未发布。
