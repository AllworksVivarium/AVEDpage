| 位置 | 内容 |
| --- | --- |
| 根目录 `server*.mjs`、`player-service.mjs` | HTTP 入口、数据库和服务端业务模块 |
| `public/` | 玩家及管理端入口、浏览器脚本、样式和素材 |
| `tools/` | 本地预览辅助、账号维护、素材导入与构建工具 |

| `tests/` | 业务、权限、数据迁移和界面回归测试 |
| `docs/` | 当前专题文档、素材许可与引用清单 |
| `docs/history/` | 按日期保留的发布、交接与文案评审记录 |
