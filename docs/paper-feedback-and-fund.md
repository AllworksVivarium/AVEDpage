# 纸面反馈、交易税费与日志保留

## 纸面反馈

- 每日签到、整点补给、个人资料保存成功时，在现有提示里加一次短暂的盖章反馈。
- 状态章保留收容物原有状态文字，列表和详情共同使用。纸纤维、油墨留白均由 CSS 绘制。
- 三个配色均继承当前主题的重点色；关闭动效或系统减少动态效果时，印章直接显示。
- 不增加请求、轮询、奖励或本地持久化。

## 交易税费

- 沿用现有成交手续费：成交额的 0.1%，向上取整，每笔至少 1 A 币。
- 每条成功的 stock_trades 记录通过数据库触发器把 fee 同额转入 company_fund，kind 为 stock_fee。手续费的扣除、交易和爱心账户入账位于同一笔交易事务内。
- 新功能首次启动时，在事务中补入现存交易明确记录的正手续费；迁移标记确保重启不会重复补入。不推算旧版本未记录的手续费。
- 爱心账户余额包含税费；员工捐款总额、个人捐款和爱心榜仍只计算 donation。
- 公司大厅及股市交易统计展示全体累计税费和成交笔数；股市另外显示个人累计手续费。
- 税费回执随爱心账户保留，员工删除、交易 ID 重用不会导致下一笔手续费被遗漏。

## 日志

- 已知普通运行记录保留 30 天；超期的浏览、登录登出、心跳等按白名单清理。
- 旧余额日志副本保留 90 天。仅当原始 balance_ledger 的 ID、员工、金额和原因均可核对时，才移除副本。
- 原始资金流水、证券交易、游戏结果、发言、图片审核及未知类型审计记录不在清理范围。
- 无线电沿用 3 天保留期。
- 启动时及此后每小时执行一次；每类每次最多 500 条，使用部分索引，不在请求处理中循环清理或自动 VACUUM。

## 新增公司播报文案

沿用三分钟一次的现有播报，不增加请求或通知种类，以下文案不改变股价：

1. 休息申请已获批准，系统将自动寻找适合休息的历史时间。
2. 员工满意度调查结果良好，不满意的问卷未通过满意度审核。
3. 为保障匿名反馈，意见箱已移至监控覆盖完整的区域。
4. 医务室已完成疲劳筛查，未能到场的员工视为精神状态良好。
5. 公司将充分尊重个人时间，具体以排班表为准。
6. 请勿擅自处理异常；已经处理完毕的，请恢复原状后补办审批。
7. 安全演练取得成功，未按计划发生的危险不计入本次评估。
8. 所有问题均已指定责任部门，解决时间不在本次统计范围内。
9. 离职流程已增设快速通道，位于普通通道审批结束后。
10. 收容物已学会模仿员工叹气，请各位降低工作示范频率。
11. 公司已取消不合理的考核指标，其余指标的合理性将由指标自行证明。
12. 档案室提醒：文件标注“永久保存”，不代表内容仍然有效。
